# Domain Constraints

- El sistema requiere conexión a internet.
- No existe modo offline.
- No hay aplicación nativa iOS.
- El pago se procesa en COP.
- La app web debe ser compatible con Chrome y Firefox.
- La aplicación móvil se implementa como PWA.
- Los reportes se generan en Word, PDF y Excel.
- La autenticación y autorización dependen de JWT y roles.
- La seguridad debe alinearse con OWASP Top 10.
- La interfaz debe cumplir accesibilidad WCAG 2.1 nivel AA.
- El sistema no incluye facturación electrónica con validez fiscal.
- El sistema no incluye contabilidad avanzada.
