# Domain Overview

El dominio del proyecto corresponde a la gestión de alquiler de vehículos.

La solución cubre el ciclo completo del negocio: consulta de flota, búsqueda y filtrado de vehículos, reservas, pagos, firma de contratos, seguimiento de reservas, gestión administrativa, auditoría y soporte.

El sistema modela los procesos principales de una empresa de rent a car, incluyendo clientes, vehículos, sucursales, reservas, contratos, pagos y roles operativos.
