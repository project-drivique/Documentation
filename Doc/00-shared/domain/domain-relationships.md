# Domain Relationships

- Un cliente puede tener muchas reservas.
- Una reserva pertenece a un solo cliente.
- Una reserva se asocia a un solo vehículo.
- Un vehículo pertenece a una sucursal.
- Una sucursal pertenece a una ciudad.
- Una reserva puede generar un contrato.
- Un contrato está ligado a una reserva confirmada.
- Un pago pertenece a una reserva.
- Una notificación puede estar asociada a un usuario y a un evento del sistema.
- Un reporte pertenece a un usuario y puede referirse a una reserva o a un vehículo.
- Un administrador puede gestionar múltiples entidades del sistema.
- Un encargado de sucursal solo opera sobre su sucursal asignada.
