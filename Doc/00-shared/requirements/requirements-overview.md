# Requirements Overview

Este proyecto define los requisitos funcionales y no funcionales de una plataforma integral de alquiler de vehículos llamada Drivique / RentaMovil.

El sistema cubre autenticación, catálogo de vehículos, reservas, pagos, contratos, perfil de usuario, notificaciones, soporte, auditoría y panel administrativo.

Los requisitos fueron derivados del SRS y organizados por módulos para facilitar el desarrollo, las pruebas y la trazabilidad.
