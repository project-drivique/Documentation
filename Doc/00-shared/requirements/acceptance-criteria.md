# Acceptance Criteria

- El usuario puede registrarse con correo y contraseña.
- El sistema valida la seguridad de la contraseña antes de crear la cuenta.
- El sistema solicita verificación de correo después del registro.
- El usuario puede iniciar sesión con credenciales válidas.
- El sistema bloquea temporalmente la cuenta tras varios intentos fallidos.
- El catálogo muestra vehículos disponibles y permite filtrar y ordenar resultados.
- El usuario puede ver el detalle completo de un vehículo.
- La reserva solo puede completarse si el usuario acepta el tratamiento de datos.
- La reserva genera un código único.
- El pago virtual se integra con Wompi.
- El pago en efectivo puede ser confirmado por el encargado de sucursal.
- El contrato solo se muestra cuando la reserva está confirmada.
- El sistema mantiene auditoría de acciones relevantes.
- La interfaz funciona correctamente en móvil y escritorio.
