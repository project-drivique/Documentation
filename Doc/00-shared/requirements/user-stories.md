# User Stories

- Como visitante, quiero explorar el catálogo para conocer los vehículos disponibles.
- Como cliente, quiero registrarme y verificar mi correo para acceder al sistema.
- Como cliente, quiero iniciar sesión para gestionar mis reservas.
- Como cliente, quiero buscar y filtrar vehículos para encontrar uno que se ajuste a mis necesidades.
- Como cliente, quiero reservar un vehículo seleccionando fechas, sucursal y servicios adicionales.
- Como cliente, quiero pagar por Wompi o en efectivo para confirmar mi reserva.
- Como cliente, quiero firmar el contrato digital para formalizar el alquiler.
- Como cliente, quiero revisar mis reservas y notificaciones.
- Como administrador, quiero gestionar vehículos, reservas, usuarios y reportes.
- Como encargado de sucursal, quiero confirmar pagos en efectivo y operar mi sede.
- Como operador, quiero registrar la entrega e inspección del vehículo.
