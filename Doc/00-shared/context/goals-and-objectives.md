# Goals and Objectives

## Goal
Desarrollar e implementar un sistema integral de alquiler de vehículos que optimice los procesos de reserva, contratación, gestión de flotas, pagos y generación de reportes, garantizando seguridad, eficiencia y accesibilidad.

## Objectives
- Analizar los procesos actuales de las empresas de alquiler de vehículos.
- Diseñar un panel administrativo para flotas, contratos, pagos, reservas, mantenimientos y notificaciones.
- Implementar una base de datos segura, una API REST, una aplicación web y una aplicación móvil bajo arquitectura en N capas.
- Integrar pagos en línea mediante Wompi.
- Generar reportes en Word, PDF y Excel.
- Garantizar seguridad OWASP Top 10, autenticación JWT y control de roles.
- Cumplir con criterios de accesibilidad WCAG 2.1 nivel AA.
