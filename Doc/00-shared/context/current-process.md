# Current Process

Actualmente, la gestión del alquiler de vehículos presenta procesos manuales o semimanuales que generan demoras y errores.

Los procesos críticos que el sistema busca reemplazar o mejorar son:
- Registro e inicio de sesión.
- Verificación del correo y recuperación de contraseña.
- Consulta y filtrado de vehículos disponibles.
- Reserva por fechas, sucursal y servicios adicionales.
- Pago virtual o en efectivo.
- Firma del contrato de alquiler.
- Gestión administrativa de flota, reservas, usuarios y reportes.
- Atención al cliente y seguimiento de incidencias.

La propuesta digitaliza estas actividades y las concentra en una aplicación web responsiva con roles diferenciados.
