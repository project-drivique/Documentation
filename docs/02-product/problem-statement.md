# Problem Statement

La industria del alquiler de vehículos presenta ineficiencias importantes debido al uso de procesos tradicionales y poco automatizados.

Entre los principales problemas identificados se encuentran:
- Reservas manuales lentas y propensas a errores.
- Gestión ineficiente de contratos.
- Sistemas de pago no integrados.
- Canales de atención al cliente restringidos.
- Falta de plataformas digitales accesibles.
- Control deficiente de la flota, disponibilidad y mantenimientos.

Estas limitaciones afectan la experiencia del usuario, reducen la eficiencia operativa y disminuyen la competitividad de las empresas del sector.
