# Glossary

- **SRS**: Especificación de Requisitos de Software.
- **RF**: Requerimiento Funcional.
- **RNF**: Requerimiento No Funcional.
- **JWT**: JSON Web Token.
- **PWA**: Progressive Web App.
- **Wompi**: Pasarela de pagos usada por el sistema.
- **OWASP**: Guía de buenas prácticas y riesgos de seguridad web.
- **WCAG 2.1**: Lineamientos de accesibilidad web.
- **API REST**: Interfaz para comunicación entre frontend y backend.
- **UI**: Interfaz de usuario.
- **CRUD**: Crear, leer, actualizar y eliminar.
- **2FA**: Autenticación de dos factores.
- **COP**: Peso colombiano.
