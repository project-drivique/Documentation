# Non-Functional Requirements

## Seguridad
- Autenticación mediante JWT.
- Control de acceso por roles.
- Protección contra vulnerabilidades OWASP Top 10.
- Cifrado SSL/TLS.
- Manejo seguro de secretos y credenciales.

## Rendimiento
- La landing page debe cargar en menos de 3 segundos.
- El sistema debe responder de forma ágil en condiciones normales.

## Usabilidad
- Interfaz limpia, intuitiva y consistente.
- Validación en tiempo real en formularios.
- Navegación clara por módulos.

## Accesibilidad
- Cumplimiento de WCAG 2.1 nivel AA.

## Compatibilidad
- Compatible con Chrome y Firefox.
- Adaptable a celulares, tabletas y escritorio.
- Aplicación web tipo PWA.
- Compatible con Android 13 y 14.

## Escalabilidad y mantenimiento
- Arquitectura en N capas.
- Separación clara de responsabilidades.
- Estructura preparada para crecer en módulos y usuarios.

## Disponibilidad
- Requiere conexión estable a internet.
- Depende del servidor y de APIs externas como Wompi.
