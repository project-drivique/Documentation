# Estrategia de ramas Git

## Ramas principales
- `main`: versión estable.
- `develop`: integración general.
- `feature/*`: nuevas funcionalidades.
- `fix/*`: correcciones.
- `hotfix/*`: correcciones urgentes.

## Reglas
- No trabajar directo sobre `main`.
- Cada funcionalidad debe ir en su propia rama.
- Todo merge debe revisarse antes de integrarse.
- Mantener commits claros y descriptivos.
