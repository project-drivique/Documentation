# Project Charter

## Nombre del proyecto
Drivique / RentaMovil

## Propósito
Diseñar e implementar un sistema integral de alquiler de vehículos con autenticación segura, gestión de reservas, pagos en línea, contratos digitales y panel administrativo.

## Objetivos
- Digitalizar el proceso de alquiler de vehículos.
- Centralizar la administración de flota, reservas y contratos.
- Mejorar la experiencia del cliente.
- Garantizar seguridad, trazabilidad y accesibilidad.

## Alcance general
La solución cubrirá cliente web responsivo, panel administrativo, gestión de usuarios, reservas, pagos, contratos, reportes y auditoría.

## Fuera de alcance
- App nativa iOS.
- Facturación electrónica fiscal.
- Modo offline.
- Contabilidad avanzada.
