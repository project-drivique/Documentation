# Visión del proyecto

Este proyecto busca desarrollar una plataforma integral de alquiler de vehículos que permita a clientes, administradores y operadores gestionar reservas, pagos, contratos, vehículos y reportes de forma digital, segura y eficiente.

El objetivo es mejorar la experiencia del usuario, reducir procesos manuales y centralizar la operación del negocio en una solución web responsiva.
