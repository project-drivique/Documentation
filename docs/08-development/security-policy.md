# Política de seguridad

- No exponer contraseñas, tokens ni claves API.
- Guardar secretos en variables de entorno.
- Proteger rutas sensibles con autenticación.
- Usar JWT con control de roles.
- Validar entradas para reducir riesgos.
- Aplicar buenas prácticas alineadas con OWASP.
- Revisar permisos antes de publicar información.
