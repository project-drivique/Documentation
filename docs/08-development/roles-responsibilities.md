# Roles y responsabilidades

## Analista
- Levantar requisitos.
- Documentar procesos.
- Revisar el SRS.

## Diseñador
- Definir estructura visual.
- Diseñar pantallas y componentes.

## Desarrollador frontend
- Implementar interfaces.
- Consumir API.
- Validar formularios y estados.

## Desarrollador backend
- Crear API REST.
- Gestionar autenticación, reglas de negocio y base de datos.

## QA / pruebas
- Validar funcionalidades.
- Reportar errores.

## Líder del proyecto
- Coordinar tareas.
- Revisar avances.
- Aprobar cambios importantes.
